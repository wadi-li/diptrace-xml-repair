Локальный сервер: папки и базы

Без сервера страница видит только файлы, выбранные вручную. С сервером — подключённые в DipTrace библиотеки, свои папки, папки 3D-моделей, замена исходного файла с резервной копией. Сервер встроен в эту страницу; интернет и GitHub не нужны.

Корпоративная сборка (для компьютеров с Kaspersky и другими строгими антивирусами): код сервера лежит отдельным файлом рядом со страницей. Распакуйте архив в любую папку, например C:\DipTrace\xml-repair, и запустите dt-xml-repair-server.ps1 правой кнопкой → «Выполнить с помощью PowerShell» (или start-server.cmd). Сервер откроет инструмент в браузере. Если запуск сценариев запрещён групповой политикой или антивирус блокирует dt-xml-repair-server.ps1, нужно разрешение администратора (исключение для этой папки); без сервера работают все проверки файлов, выбранных вручную.
Первый запуск на этом компьютере. Браузер не может сам запускать программы, поэтому один раз: нажмите «Скачать DipTrace-XML-Repair.cmd» и откройте файл из панели загрузок (браузер или SmartScreen могут попросить подтвердить: «Сохранить» / «Подробнее → Выполнить в любом случае»). Файл копирует себя как обычный сценарий %LOCALAPPDATA%\dt-xml-repair\server.ps1 и запускает его в Windows PowerShell — без установки и прав администратора, реестр не трогает. Если антивирус или политика не дают запустить .cmd, скачайте server.ps1 и запустите его через контекстное меню «Выполнить с помощью PowerShell». Чтобы потом запускать кнопкой «Запустить сервер», в разделе «Папки и базы» (уже с сервером) скачайте и импортируйте файл быстрого запуска .reg.

3D-модели: наличие файлов

Настройка автоматической проверки

Браузер не может сам читать диск, поэтому список файлов готовит сценарий dt-models3d-index.cmd. Положите его в ту же папку, что и этот HTML, и запустите двойным щелчком: он запишет рядом dt-models3d-index.js со списком файлов обеих папок. Инструмент читает этот список сам — при открытии и по кнопке «Проверить 3D-модели». Содержимое моделей не читается и из OneDrive не скачивается; файлы «только в облаке» отмечаются отдельно. После добавления моделей запустите сценарий снова.

«всегда» — исправляется самим разбором файла при любом сохранении (обрезанные теги, мусор, NUL, неэкранированные символы). Щёлкните по строке, чтобы увидеть все места.

4. Исправление

Перед открытием в DipTrace закройте исходную библиотеку и откройте исправленную через «Library / Open» (или импорт DipXML) в отдельной группе. Если библиотека была подключена в «Library Setup», замените файл после проверки.

5. Поиск причины зависания

Если проверка не находит ошибок, а DipTrace всё равно зависает, причину ищут делением: инструмент формирует две половины библиотеки, вы открываете каждую в DipTrace и отмечаете результат. За ~log₂N шагов остаётся один корпус или компонент. У тестовых копий меняются Name и UID32, чтобы они не конфликтовали с основной библиотекой в Library Manager.

Проверка гипотез на всей библиотеке

Каждый вариант — копия библиотеки без одного класса данных. Если какой-то вариант открывается, а исходный нет — причина в этом классе данных.

Ручной выбор объектов

Если файл в порядке, а DipTrace зависает

  • Повреждённые настройки групп библиотек. По совету поддержки DipTrace на форуме: временно переименуйте libgroups.dat и libgroups_var.dat в C:\ProgramData\DipTrace\Data_Unicode (или всю папку) — при запуске они создаются заново; затем подключите библиотеки снова. Форум DipTrace
  • Файлы OneDrive «только в облаке». Библиотеки и 3D-модели в OneDrive\DipTrace при открытии могут скачиваться; при плохой связи это выглядит как зависание. Отметьте папку «Всегда хранить на этом устройстве». Вариант «без ссылок на 3D-модели» в разделе 5 помогает это проверить.
  • Сетевые пути \\сервер\… к моделям или библиотекам — при недоступном ресурсе Windows ждёт тайм-аут.
  • Установка в Program Files. Поддержка DipTrace рекомендует ставить программу в отдельную папку, например C:\DipTrace. FAQ DipTrace
  • Если найден конкретный корпус, а формальных ошибок в нём нет — отправьте его копию («Скачать только его») в support@diptrace.com.

Проверки построены по спецификациям формата, сгенерированным из сериализатора DipTrace: Pattern Editor XML, Component Editor XML. Сохранение без правок повторяет файл побайтно (проверяется при загрузке).
